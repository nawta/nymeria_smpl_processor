# Third-party code

This directory is a copy of [articulate](https://github.com/Xinyu-Yi/articulate) by Xinyu Yi, a toolkit for articulated body models used in TransPose and PIP. `model.py` is in turn modified from [CalciferZh/SMPL](https://github.com/CalciferZh/SMPL).

Neither upstream repository includes a license file, so the copyright stays with the original authors. Contact them before reusing this code outside this project.
